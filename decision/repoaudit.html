Irregularities found on this pass
# Irregularity Assessment Suggested handling Source
R-01 More than a dozen parallel editions of the same analysis are published and interlinked from the root. Irregular. Not a legal problem, but it makes the record hard to rely on and hard to review. Mark superseded editions clearly at the top of each, or archive them behind a single index. See suggestion S-16. S07
R-02 Several preserved editions predate the 2026-11-09 Rent Board notice about File No. 261020 and therefore present banked-increase guidance without that warning. Irregular. Material omission, not an error in the figures. Either withdraw the affected pages or add the warning. Suggestion S-16. S20 S07
R-03 The root index.html cannot be edited without also editing hub/build.py and re-running the “Final assurance” workflow. By design, but constraining. A new consolidated edition therefore cannot become the root page without taking over a completed session's files. Either leave the root as is and publish consolidated editions underneath it (what this session did), or have one session own the root and regenerate it. See F-14. S01
R-04 Earlier public Git history reportedly contains tenant initials; pre-redaction blobs persist below an early PR. Serious privacy irregularity. Current-file scans do not detect or repair history. Requires an administrator history rewrite. No session should attempt it unilaterally. See F-15 and suggestion S-17. S02
R-05 COORDINATION.md has grown past 200 KB through repeated append-only session addenda. Irregular but harmless. It is a log, not a deliverable. Trim completed session records into audit/ at the next integration pass. S01
R-06 One earlier session's record notes that a commercially sourced page was still being served from a legacy edition. Irregular. Commercial summaries are not official sources. Withdraw commercial content from served pages or relabel it clearly as unofficial. See suggestion S-18. S03
R-07 The “sources” count differs between editions (29, 31, 33, 34, 42 across various builds). Not an error — each edition registered a different set. But a reader cannot tell which count is current. This edition states its own count (22) and lists every source with its verified passage. See the sources page. S01
