## Privacy control (important)

All tenant and owner personal information is treated as **internal only**. This repository is
**public** (it publishes a public GitHub Pages site), so no real names, initials, unit addresses,
or emails are stored in any tracked file — including commit messages and page metadata. Tenants are
represented by role identifiers (`Tenant A-1` … `Tenant B-2`). **Dates and dollar amounts are kept
exactly as supplied**, because the legal analysis depends on them.

Mapping from role identifiers back to real individuals lives only in the owner's private records
(it is derivable from the original brief). It is intentionally **not** committed here.
