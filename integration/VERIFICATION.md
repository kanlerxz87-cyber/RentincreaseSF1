## Scope and method

This is a fresh, concise integration edition. Each data row has a direct official source link. Owner-supplied case facts are explicitly unverified, with empty official-confirmed cells. Official sources support the governing rule, not the private fact. Illustrations are calculated from those reported figures, not asserted as lawful maxima. No actual attorney reviewed the case. This is not a claim that all historical editions have been checked line by line or corrected.
