Calculations

Both units, every scenario, with the arithmetic shown and a source link on every component.

Every figure on this page is computed by adding published percentages and applying the total once to the current base rent. Percentages are never compounded and amounts are never rounded up. Each component links to the Rent Board table it came from.

The two rules that do all the work

Add, never compound. Banked percentages are added together, then multiplied by the current base rent once. S04 S05

24 months, not 12. A skipped annual increase is only banked if at least 24 full months pass without any rent increase. If less than 24 months pass, the skipped increase is lost. S04 This is the rule that produces Unit 2's large figure and the rule that limits Unit 1's small one.

The maximum lawful increase differs sharply between the two units even though they are in the same building, because the legal ceiling is a function of each tenancy's own history of skipped increases - not of the unit's size, condition, or market rent.

Arithmetic checks

  • Percentages are added, never compounded. Source S04 and S05.
  • The dollar amount is the total percentage multiplied by the CURRENT base rent, not by each year's rent. Source S04.
  • No rounding up to the nearest dollar is permitted. Source S01.
  • Unit 1 check: 3995 x 0.016 = 63.92 exactly; 3995 x 0.030 = 119.85 exactly.
  • Unit 2 check: 3150 x 0.131 = 412.65 exactly; 3150 x 0.016 = 50.40 exactly.

These were also verified independently by script; see Method.

What is deliberately blank

Any increase effective on or after March 1, 2027 is left blank, because the 2027–28 rate had not been announced as of 2026-11-06. The Rent Board announces it each January. A blank is more useful to you than an estimate that later turns out to be wrong. S02

Verification standard. Every value in a table is traceable to a numbered source linked in the row. Where a value could not be confirmed from an official source it is left blank, marked — unverified, and listed on Flagged for review. Nothing is inferred.
